- **volleyd, volley-hooks: Claude pickers and coordinator handoffs in the needs-you inbox.** Two new hooks on `AskUserQuestion` publish `progress/picker_opened { tool_use_id, questions }` and `picker_answered { tool_use_id, answers }`; volleyd opens a `p-<agent_id>-<tool_use_id>` item for every picker in any session, and an `h-<agent_id>-<seq>` item for a coordinator turn that ends on a question (a coordinator's own items are answered only by that session or the coordinator name bound to it). A Desk answer is carried out on the session's screen before it is accepted: volleyd checks the same picker is still shown (else `picker not on screen`) and selects the answer by keystroke, or types a handoff reply into an idle prompt (else `prompt not idle`); `Up`/`Down`/`Space` and the typed text pass the fence only with a `PickerToken` / `HandoffToken` for exactly that item and answer. The picker's own hook, the session's next prompt, or the session ending closes the item with `where: terminal` when it was answered there. The volley-issues skill asks go/no-go through `AskUserQuestion` (`go`, `hold`, `cancel`). (#206)

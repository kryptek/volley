- **volleyd: a wave names a repository held only by paired machines by its owner/name.**
  `repo: owner/name` resolves to the supervisor's clone when its machine holds one, is kept as the
  owner/name when only paired machines hold it (its tasks are placed there; the supervisor needs no
  checkout and runs its `gh` work with `--repo`), and is refused only when no machine holds it,
  naming them; a task of such a wave pinned to `host: local` is refused at submit with
  `placement: auto` as the fix. `volleyd validate` gives the same verdict offline and both CLIs
  print a `repo:` line. (#448)

- **volleyd: autopilot merges a draft PR instead of escalating `merge_refused`.** A draft is
  marked ready (`gh pr ready`, journaled `pr_marked_ready { pr, head, at }`) before the CI gate,
  and the gate counts only the runs created after the mark, so the jobs a repository skips on
  drafts actually run. A merge refused because the PR is a draft (`reason: draft`) marks it ready,
  holds the gated head for that CI and merges once it is green; it never uses up
  `merge_retry_max`, and autopilot's `merge_refused/draft` row answers `retry`.
